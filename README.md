# vyron

Статический сайт бренда одежды vyron: каталог футболок и свитшотов с принтами, корзина, избранное и оформление заказа через мессенджеры. Без сборщиков, фреймворков и бэкенда - только HTML, CSS и ванильный JavaScript.

## Запуск

Сайт работает без сборки. Достаточно открыть `index.html` в браузере или поднять любой статический сервер из корня проекта:

```
python -m http.server 8000
# или
npx serve .
```

Затем открыть `http://localhost:8000`.

## Возможности

- Три языка интерфейса: русский, английский, азербайджанский. Переключение в шапке и в мобильном меню.
- Три валюты: USD, RUB, AZN. Цены пересчитываются на лету, включая фильтр по цене.
- Скидка открытия: зачёркнутая старая цена считается из базовой по формуле `цена / (1 - discountRate)`.
- Каталог: фильтры по категории, размеру и цене; сортировка; поиск по названию; постепенная догрузка.
- Корзина и избранное хранятся в localStorage и переживают перезагрузку.
- Быстрый просмотр товара из карточки, лайтбокс с зумом на странице товара.
- Оформление заказа без форм: сайт открывает Telegram или WhatsApp с готовым текстом заказа.
- Автоматический фолбэк изображений: если файл не найден, пробуются расширения png, jpg, jpeg, webp, затем показывается заглушка.

## Настройка

Все ключевые значения собраны в `js/config.js`:

| Параметр | Назначение |
| --- | --- |
| contacts | Ссылки на Telegram, WhatsApp, YouTube, TikTok |
| currencies | Курсы, символы и точность валют |
| discountRate | Величина скидки для зачёркнутых цен |
| defaults | Язык и валюта по умолчанию |

Товары редактируются в `js/catalog.data.js`: название, коллекция, тип, состав, размеры с ценами в USD и список изображений. Локализация названий и описаний - в `js/i18n.js` внутри блока `prodItems`.

## Регенерация каталога

Скрипт сканирует `assets/products` и пересобирает `js/catalog.data.js`:

```powershell
powershell -ExecutionPolicy Bypass -File tools/generate-catalog.ps1
```

После генерации нужно вручную заполнить переводы новых позиций в `js/i18n.js`.

## Особенности контента

- В текстах сайта запрещены длинные тире - используется обычный дефис.
- Файлы `description.txt` внутри ассетов не используются сайтом и служат заметками владельца.
- Instagram сейчас скрыт: в конфиге стоит заглушка, кнопка рендерится неактивной.
